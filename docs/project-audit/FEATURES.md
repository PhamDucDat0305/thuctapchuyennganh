## Tổng kết mức hoàn thiện

- Backend/API bao phủ nhiều luồng nghiệp vụ chính, parameterize hầu hết input SQL và lấy user ID từ session.
- Các trang HTML thường gọi adapter `window.DB`; các chức năng không có API tương ứng không được xem là backend feature. OTP email chỉ phục vụ đăng ký, không phải MFA hoặc thông báo nghiệp vụ.
- Runtime schema không đồng nhất có thể xảy ra vì migrations không dựng bảng lõi và nhiều script không nâng cấp bảng tồn tại đầy đủ.

# Danh sách chức năng

**Quy ước xác minh:** “Có code — runtime chưa xác minh” nghĩa là có đường giao diện/handler và liên kết API trong source, nhưng audit không chạy app/DB. “Có bằng chứng người dùng” chỉ áp dụng các luồng người dùng đã báo chạy thành công trong trao đổi trước; không thay thế test lặp lại.

## Tổng kết mức hoàn thiện

- Backend/API bao phủ nhiều luồng nghiệp vụ chính, parameterize hầu hết input SQL và lấy user ID từ session.
- Các trang HTML thường gọi adapter `window.DB`; một số khả năng chỉ là UI/cache, không có tương ứng đầy đủ trong backend (đặc biệt 2FA, login history, upload/reset password).
- Runtime schema không đồng nhất có thể xảy ra vì migrations không dựng bảng lõi và nhiều script không nâng cấp bảng tồn tại đầy đủ.
